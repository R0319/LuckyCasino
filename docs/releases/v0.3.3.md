プラグインを入れ替えたときなどに、カジノの実績が消えてしまうことがある問題に対策しました。

## 直したこと
- マインクラフトは、サーバーに読み込まれていない実績の進み具合を、プレイヤーのデータから消してしまいます。LuckyCasino の実績はプラグインが読み込むので、プラグインを外している間や入れ替えの途中のサーバーに入ると、その人のカジノの実績が消えていました（`/minecraft:reload` のあとも同じ）
- 解除した実績を `plugins/LuckyCasino/achievements.yml` にも書いておき、サーバーに入ったときと読み込み直しのあとに、消えていたものを戻すようにしました（戻すときはチャットに出しません）
- この版を入れたあとに入った人は、そのときに持っている実績が記録されます。それより前に消えてしまった実績は戻りません

## 0.3.2 から上げるとき
- jar だけ入れ替えてください。リソースパックは入れ替えなくても動きます（言語ファイルにサーバーのログ用の文が 2 つ増えただけです）
- 0.3.2 の jar は消してから入れてください（同じプラグインが 2 つあると読み込めません）。jar を消してから新しい jar を入れるまでの間は、サーバーを起動しないでください

---

Casino achievements could disappear when the plugin was missing (e.g. while swapping jars) or after `/minecraft:reload`, because Minecraft drops progress for advancements that are not loaded. LuckyCasino now also records unlocked achievements in `plugins/LuckyCasino/achievements.yml` and restores missing ones when a player joins or after a reload (without chat messages). Achievements lost before this version cannot be restored automatically. Only the jar needs updating.
