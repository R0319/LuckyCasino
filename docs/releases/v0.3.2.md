サーバーに入るたびに起きていたリソースパックの読み込みを、プレイ中ではなく読み込み画面の間に済ませるようにしました。

## 変更
- リソースパックを、参加したあと（ワールドに入ってから）ではなく参加の前（読み込み画面）に送ります。読み込みが終わってからワールドに入るので、プレイ中に画面が止まらなくなります

## 追加
- `config.yml` の新しい設定 `resource-pack.mode`
  - `external`: Nexo などのパックに LuckyCasino のパックを混ぜて配るときや、プロキシ（Velocity）のプラグインで配るとき。LuckyCasino はパックを送らず、Java 版の人には全員カードの絵（ルールブックの絵・メニューの背景）を出します。配る側でパックを必須にしておいてください
  - `off`: 送らず、絵も出しません
  - 空（既定）: これまでどおり、`url` があれば送り、無ければ送りません
- これまでは `resource-pack.url` が空のサーバーでは、ほかの仕組みでパックが入っていても絵が出ませんでした。`external` にすると出ます

## 0.3.1 から上げるとき
- jar だけ入れ替えてください。リソースパックは 0.3.1 と同じです（`resource-pack.sha1` はそのまま）
- Nexo などでパックを配っているサーバーは、`config.yml` の `resource-pack:` に `mode: external` を足してください
- 0.3.1 の jar は消してから入れてください（同じプラグインが 2 つあると読み込めません）

---

The resource pack is now sent during the configuration phase (loading screen) instead of after joining, so the game no longer freezes after you enter a server. New setting `resource-pack.mode`: set `external` when another plugin (e.g. Nexo) or a proxy plugin delivers a pack that includes LuckyCasino's; LuckyCasino then sends nothing and shows the card glyphs to every Java player. Only the jar changes; the resource pack is the same as 0.3.1.
