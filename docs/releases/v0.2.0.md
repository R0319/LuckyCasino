Purpur / Paper 26.2 向けに作り直したカジノプラグインです。9 種類のゲームを、ItemDisplay とリソースパックのモデルで表示して遊べます。

## ゲーム
- ブラックジャック・ルーレット（ヨーロピアン）・ポーカー（テキサスホールデム）
- スロット（5 ライン、レバーで回す）
- バカラ・ハイ＆ロー
- ビッグホイール（ステージ）・競馬（直線コース）・チンチロ（座敷）

## おもな機能
- Vault の経済プラグインがあればお金で両替し、無ければ練習用のチップで遊ぶ
- どの卓でもスニークで立って、卓のまわりを歩ける（精算はメニューの「席を立つ」か `/casino leave`）
- ルールブック（Java 版でパックを読み込んだ人には絵が中心のページ）、実績 11 個、ディーラーの見た目のメニュー
- テーブルごとのクラフトレシピ（`config.yml` の `recipes`）
- どの賭け方も還元率は 100% 未満（一覧は README）。ブラックジャックとバカラは勝負ごとに山を切り直す

## 入れ方
1. `LuckyCasino-Paper-0.2.0.jar` を Paper / Purpur 26.2 の `plugins/` に入れる（Java 21 以上）
2. `LuckyCasino-java-pack.zip` をサーバーのリソースパックとして配る（`config.yml` の `resource-pack` に URL と sha1 を書く）
3. 統合版向けの `LuckyCasino-Geyser-0.2.0.jar` は Geyser の `extensions/` 用です（統合版の表示はまだ作っている途中です）
