ゲームの中の文を英語に対応しました。

## 追加
- 英語（メニュー・チャット・卓の上の文字・ルールブック・実績）
  - リソースパックを入れた Java 版の人には、その人のゲームの言語で出ます（日本語以外はすべて英語）。卓の上の文字も、見る人ごとに変わります
  - パックを入れていない人・統合版の人・サーバーのログは、`config.yml` の新しい設定 `language`（`ja` / `en`、既定 `ja`）の言語です
  - ルールブックは、パックの有無にかかわらずその人のゲームの言語で開きます

## 0.3.0 から上げるとき
- jar とリソースパックを入れ替えてください。パックに言語ファイルが増えたので、`config.yml` の `resource-pack.sha1` も新しい zip の値に直してください
- 英語のサーバーにするときは、`config.yml` に `language: en` を足してください（無ければ日本語）
- 0.3.0 の jar は消してから入れてください（同じプラグインが 2 つあると読み込めません）

---

In-game text is now available in English. Java players with the resource pack see their own game language; players without the pack, Bedrock players and the server log use the new `language` setting in `config.yml` (`ja` by default, `en` for English). Update both the jar and the resource pack (and its `resource-pack.sha1`).
