# LuckyCasino

Purpur / Paper 26.2 向けのカジノプラグインです。ブラックジャック・ルーレット・ポーカー（テキサスホールデム）のテーブルを置いて遊べます。カード・チップ・ホイールはすべて ItemDisplay とリソースパックのモデルで表示し、配る・回す・払い出す動きは Display の補間で見せます。

- 経済プラグイン（Vault 経由）があるサーバーではお金をチップに両替して遊び、席を立つとお金に戻ります。無いサーバー（hub など）では練習用チップを無料で配ります。
- 統合版（Geyser）向けの表示は Geyser 拡張（`geyser/`）で準備中です。今はブラックジャックのカードだけが対象で、ポーカーの手札・ルーレット・チップは統合版では見えません。

## 構成

| フォルダ | 内容 |
| --- | --- |
| `common/` | ゲームの進行（ブラックジャック・ルーレット・ポーカー）。Bukkit に依存しない純粋な Java で、単体テスト付き |
| `paper/` | Paper プラグイン本体（テーブルの表示、席、メニュー、コマンド） |
| `geyser/` | 統合版にカードを見せる Geyser 拡張 |
| `resourcepacks/` | Java 版・統合版のリソースパック（`tools/` のスクリプトで生成） |
| `tools/` | テクスチャ・モデルの生成（Python 3 + Pillow）。生成物はコミット済みなので、ビルドに Python は不要 |
| `dist/` | 試験配信用のビルド済み Java 版リソースパック |

## ビルド

Java 25 が必要です（Paper 26.2 の API が Java 25 向けのため）。

```
./gradlew build
```

| 出力 | 置き場所 |
| --- | --- |
| `paper/build/libs/LuckyCasino-Paper-0.1.0-SNAPSHOT.jar` | Paper（Purpur）の `plugins/` |
| `paper/build/resourcepack/LuckyCasino-java-pack.zip` | Java 版プレイヤーへ配信（下の「リソースパック」） |
| `geyser/build/libs/LuckyCasino-Geyser-0.1.0-SNAPSHOT.jar` | Velocity の `plugins/Geyser-Velocity/extensions/` |

## 遊び方（共通）

1. テーブルを手に入れる：クラフトか、管理者が `/casino give <blackjack|roulette|poker>`
2. ブロックの上面に右クリックで置く（4 x 2 ブロック、高さ 2 の空きが必要。手前に椅子、奥にディーラーが出る）。保護プラグイン（GriefPrevention など）で建築できない場所には置けません
3. 椅子をクリック → チップに両替して座る
4. 座ったまま椅子かテーブルをクリックすると、そのゲームのメニューが開く
5. スニークで席を立つとチップをお金に戻す（勝負の途中なら、勝負が終わってから精算）

置いた人はスニーク + 右クリックでテーブルを片付けられます（座っている人がいないときだけ）。各メニューの本のアイコンか `/casino rules` でルールブックを読めます。

### クラフト

| テーブル | 上段 | 中段 | 下段 |
| --- | --- | --- | --- |
| ブラックジャック | 緑のカーペット ×3 | 板材 ×3 | 金インゴット（中央） |
| ルーレット | 赤・黒・赤のカーペット | 板材・金インゴット・板材 | 板材（両端） |
| ポーカー | 緑のカーペット ×3 | 板材・エメラルド・板材 | 板材（両端） |

`config.yml` の `recipes` で変えられます（`enabled: false` で無効）。

### ブラックジャック（5 席）

賭け金メニューで額を決めると、全員が決めるか締め切り（15 秒）で配り始めます。自分の番にチャットのボタン（ヒット / スタンド / ダブルダウン / スプリット）を押します。20 秒で自動スタンド。6 デッキ、ディーラーはソフト 17 で止まる、ブラックジャックは 3:2。

### ルーレット（5 席、ヨーロピアン）

賭けのメニューは外側の賭け（赤黒・偶奇・前半後半・ダズン・縦の段）のページから開きます。下の段で 1 回に置くチップの額を切り替え、本のアイコンで数字の盤へ移ると、賭け方（1 つ・スプリット・ストリート・コーナー・ライン）を選んで数字に賭けられます。メニューのタイトルにいつも手元のチップと賭けた合計を出します。最初の人が賭けてから 20 秒で締め切り、ホイールとボールが回って止まった数字で払い戻します。結果は先に決めてから、ボールがそのポケットに止まるように動きを逆算しています。

賭けを置いたあとと、回っている間は、スニークで立っても精算せず、卓のまわりを自由に歩けます（`roulette.standing-range`、既定 8 ブロック以内）。立ったままテーブルをクリックすると賭けのメニュー、自分の椅子をクリックすると座り直し。範囲の外に出るかログアウトすると精算します（賭けが残っていれば、その回が終わってから）。

### ポーカー（6 席、テキサスホールデム・ノーリミット）

2 人そろうと 5 秒後に配ります。手札は本人にだけ表が見え、ほかの人には裏が見えます（ショーダウンで表に返る）。自分の番にはチャットに行動のボタン（フォールド / チェック / コール / ベット・レイズ / オールイン）が出ます。「金額を選ぶ」でレイズ額のメニューが開きます。25 秒で自動的にチェックかフォールド。ディーラーは配るだけで、手数料は取りません。サイドポット、足りないオールインでレイズが再開しないこと、誰も合わせなかった額の返却に対応しています。

## コマンド

| コマンド | 内容 |
| --- | --- |
| `/casino hit` `stand` `double` `split` | ブラックジャックの行動 |
| `/casino fold` `check` `call` `allin` | ポーカーの行動 |
| `/casino raise [合計]` | ポーカーのベット・レイズ（額はそのラウンドで出す合計。省略するとメニュー） |
| `/casino bet` | 賭けのメニューを開き直す |
| `/casino leave` | 席を立つ |
| `/casino rules [種類]` | ルールブック |
| `/casino give <種類> [プレイヤー]` | テーブルを渡す（管理者） |
| `/casino remove` | 近くのテーブルを片付ける（管理者。座っている人は精算） |
| `/casino status` | 通貨と Geyser 拡張の状態（管理者） |
| `/casino selftest <種類> [回数]` | ボットだけで卓を回して確かめる（管理者。コンソールからも可） |

権限は `luckycasino.place`（テーブルを置く、既定で全員）と `luckycasino.admin`（既定で OP）です。

## チップとお金

- `economy.mode` が `auto` なら、Vault の経済プラグインがあればそのお金、無ければ練習用チップ。`money-per-chip` でチップ 1 枚の値段を決めます。
- 席に着いている間のチップ（賭けている分を含む）を `plugins/LuckyCasino/chips.yml` に控えています。勝負の途中でサーバーが落ちても、次の起動時にお金に戻します。精算するときは控えを先に消してからお金を戻すので、二重には戻りません。
- チャンクの読み込みが外れたりサーバーを止めたりしてテーブルが片付くときは、勝負の途中でも賭け金をそのまま返して精算します。

## 自己テスト

`/casino selftest <種類> [回数]` は、ワールドの初期地点の近くに保存しない卓を出し、全席にボットを座らせて指定回数（既定 10）だけ勝負させます。毎回、次を確かめてサーバーのログに結果を出します。

- チップの合計が、配った分と払い戻し・賭け金の差し引きに一致する（ポーカーは席の間で動くだけ）
- 勝負の区切りで賭けたままのチップが残っていない
- 勝負の区切りで、カード・チップ・文字のエンティティが片付いている
- 進行中に例外が出ていない、進行が止まっていない

## リソースパック

`config.yml` の `resource-pack.url` と `resource-pack.sha1` を設定すると、参加した Java 版プレイヤーにパックを送ります。試験用に、ビルド済みの zip を `dist/` に置いています（GitHub の raw URL をコミット固定で指定して配信）。パックを変えたら `tools/` で `python3 gen_table.py`（カードは `gen_cards.py`）を実行し、`./gradlew build` のあと zip を `dist/` へコピーして SHA-1 を更新してください。

## 統合版（Geyser 拡張）

```
Paper（hub / survival）                         Velocity
 ├ ItemDisplay … Java 版に見えるカード            └ Geyser-Velocity
 └ TextDisplay（文字も背景も空）… 運び役              └ LuckyCasino 拡張
      Java 版では何も描かれない                          運び役を luckycasino:card に差し替え
        │                                                  ↑
        └── LAN 内 TCP（共有鍵で認証）: 「この運び役は♠A・表向き」 ──┘
```

1. Geyser 拡張を入れて Velocity を起動すると `plugins/Geyser-Velocity/extensions/luckycasino/config.properties` ができ、共有鍵 `key` が自動生成されます。
2. Paper 側の `config.yml` の `bridge` に、Velocity マシンの LAN 内 IP、ポート（既定 `25590`）、同じ `key` を書いて再起動します。
3. ポートは LAN 内からだけ届くようにしてください。

裏向きのカードは番号 0 で送るので、通信や統合版クライアントから伏せ札は読めません。Geyser は API 2.11.0 以上が必要です。

## アニメーションのプレビュー

`dist/preview.html` をブラウザで開くと、3 ゲームの 1 回分の勝負を、リソースパックのモデルとプラグインと同じ位置・tick で再生します（three.js を CDN から読み込みます）。モデルやテクスチャ、`tools/preview/preview.js` を変えたら `tools/preview` で `python3 build.py` を実行して作り直してください。動きのタイミングを Java 側で変えたときは、`preview.js` の同じ箇所も合わせて直します。
