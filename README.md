# LuckyCasino

Purpur / Paper 26.2 向けのカジノプラグインです。ブラックジャック・ルーレット・ポーカー（テキサスホールデム）・バカラ・ビッグホイール・チンチロ・ハイ＆ロー・競馬のテーブルと、スロットマシンを置いて遊べます。カード・チップ・ホイール・リールはすべて ItemDisplay とリソースパックのモデルで表示し、配る・回す・払い出す動きは Display の補間で見せます。

- 経済プラグイン（Vault 経由）があるサーバーではお金をチップに両替して遊び、席を立つとお金に戻ります。無いサーバー（hub など）では練習用チップを無料で配ります。
- 統合版（Geyser）向けの表示は Geyser 拡張（`geyser/`）で準備中です。今はブラックジャックのカードだけが対象で、ポーカーの手札・ルーレット・チップは統合版では見えません。

## 構成

| フォルダ | 内容 |
| --- | --- |
| `common/` | ゲームの進行と配当（ブラックジャック・ルーレット・ポーカー・スロット・バカラ・ビッグホイール・チンチロ・ハイ＆ロー・競馬）。Bukkit に依存しない純粋な Java で、単体テスト付き |
| `paper/` | Paper プラグイン本体（テーブルの表示、席、メニュー、コマンド） |
| `geyser/` | 統合版にカードを見せる Geyser 拡張 |
| `resourcepacks/` | Java 版・統合版のリソースパック（`tools/` のスクリプトで生成） |
| `tools/` | テクスチャ・モデルの生成（Python 3 + Pillow）。生成物はコミット済みなので、ビルドに Python は不要 |
| `dist/` | 試験配信用のビルド済み Java 版リソースパック |

## ビルド

Java 25 が必要です（Paper 26.2 の API が Java 25 向けのため）。

```
./gradlew build
```

| 出力 | 置き場所 |
| --- | --- |
| `paper/build/libs/LuckyCasino-Paper-0.1.0-SNAPSHOT.jar` | Paper（Purpur）の `plugins/` |
| `paper/build/resourcepack/LuckyCasino-java-pack.zip` | Java 版プレイヤーへ配信（下の「リソースパック」） |

## 遊び方（共通）

1. テーブルを手に入れる：クラフトか、管理者が `/casino give <blackjack|roulette|poker|slot>`
2. ブロックの上面に右クリックで置く（テーブルは 4 x 2 ブロック、高さ 2 の空きが必要で、手前に椅子、奥にディーラーが出る。スロットは 1 x 1 ブロック・高さ 2 で、手前に椅子）。保護プラグイン（GriefPrevention など）で建築できない場所には置けません
3. 椅子をクリック → チップに両替して座る
4. 座ったまま椅子かテーブルをクリックすると、そのゲームのメニューが開く
5. スニークで椅子から降りても席とチップは残り、卓のまわり（既定 8 ブロック）を歩ける。自分の椅子のクリックで座り直す
6. メニューの「席を立つ」か `/casino leave`、または卓から離れすぎるとチップをお金に戻す（勝負の途中なら、勝負が終わってから精算）

置いた人はスニーク + 右クリックでテーブルを片付けられます（座っている人がいないときだけ。立って歩いている人や勝負の途中で席を立った人も「座っている人」に数えます）。`/kill` などでテーブルの表示が消されたときは、すぐ作り直します（勝負の途中なら賭けていた分を戻して全員を精算）。`/fill` などでバリアが空気にされたときも置き直します。

置いた人（と管理者）はディーラーをスニーク + 右クリックすると、見た目のメニューを開けます。手に持った物を枠に重ねてクリックすると、その写しを着せます（手元の物は減らず、着せた物は取り出せません）。スキン（プレイヤー名）と頭の上の名前も変えられ、卓ごとに tables.yml へ保存します。各メニューの本のアイコンか `/casino rules` でルールブックを読めます。リソースパックを読み込んだ Java 版の人には、サイコロ・カード・ルーレットの盤・ホイールのマスなどの絵を主にしたページで出し、統合版とパックを断った人には文字だけのページで出します（見本は `tools/preview/rulebook.py` で `dist/rulebook.html` に描けます。先に `./gradlew :paper:test` でページを書き出しておきます）。

### 還元率（賭け金に対して戻る額の平均）

どの賭け方も 100% を下回り、続けるほど胴元が勝ちます（`common` の `ReturnToPlayerTest` で全部の賭け方を確かめ、一覧を出します）。

| ゲーム | 還元率 |
| --- | --- |
| ブラックジャック（基本戦略） | 約 99.3〜99.5% |
| バカラ | プレイヤー 98.8%、バンカー 98.9%、タイ 85.6%、ペア 約 89.6% |
| チンチロ（子） | 98.1% |
| ルーレット | 97.3%（どの賭け方も同じ） |
| スロット | 96.0%（設定で変わる。100% 以上にすると起動時に警告） |
| ハイ＆ロー | 95% 以下 |
| 競馬 | 90% 以下 |
| ビッグホイール | 1 は 88.9%、2 は 83.3%、ほかは 76〜81% |

ブラックジャックとバカラは勝負ごとに山を切り直すので、出たカードを数えても有利になりません。席に人がいる間は卓のまわりのチャンクを読み込んだままにするので、勝負の途中で遠くへ移動してチャンクを読み込み解除させ、賭け金を取り戻すこともできません。

### ブラックジャック（5 席）

賭け金メニューで額を決めると、全員が決めるか締め切り（15 秒）で配り始めます。自分の番にチャットのボタン（ヒット / スタンド / ダブルダウン / スプリット）を押します。20 秒で自動スタンド。6 デッキ、ディーラーはソフト 17 で止まる、ブラックジャックは 3:2。

### ルーレット（5 席、ヨーロピアン）

賭けのメニューは外側の賭け（赤黒・偶奇・前半後半・ダズン・縦の段）のページから開きます。下の段で 1 回に置くチップの額を切り替え、本のアイコンで数字の盤へ移ると、賭け方（1 つ・スプリット・ストリート・コーナー・ライン）を選んで数字に賭けられます。メニューのタイトルにいつも手元のチップと賭けた合計を出します。最初の人が賭けてから 20 秒で締め切り、ホイールとボールが回って止まった数字で払い戻します。結果は先に決めてから、ボールがそのポケットに止まるように動きを逆算しています。

ほかの卓と同じく、スニークで立っても精算せず、卓のまわりを自由に歩けます（`roulette.standing-range`、既定 8 ブロック以内）。立ったままテーブルをクリックすると賭けのメニュー、自分の椅子をクリックすると座り直し。範囲の外に出るかログアウトすると精算します（賭けが残っていれば、その回が終わってから）。

### ポーカー（6 席、テキサスホールデム・ノーリミット）

2 人そろうと 5 秒後に配ります。手札は本人にだけ表が見え、ほかの人には裏が見えます（ショーダウンで表に返る）。自分の番にはチャットに行動のボタン（フォールド / チェック / コール / ベット・レイズ / オールイン）が出ます。「金額を選ぶ」でレイズ額のメニューが開きます。25 秒で自動的にチェックかフォールド。ディーラーは配るだけで、手数料は取りません。サイドポット、足りないオールインでレイズが再開しないこと、誰も合わせなかった額の返却に対応しています。

### スロット（1 人用）

リール 3 本で、横 3 本（上・中・下の段）と斜め 2 本の 5 ラインをいつも全部見ます。1 回の賭け金は 5 ラインに等分し（1 回 10 / 50 / 100 枚 = 1 ライン 2 / 10 / 20 枚）、当たったラインの配当を合計して戻します。当たったラインには光る帯が点滅します。台をクリックすると賭け金のメニュー、台の右のレバーをクリックすると回ります（メニューの「回す」と `/casino spin` でも回せます）。チャットには結果と、当たったラインと役だけを出します。止まる位置は先に乱数で決め、リールがそこに止まるように動きを逆算しています。どれかのラインで左の 2 本が 7 か BAR でそろうとリーチになり、そのラインが点滅して右のリールが長く回ります。

| 役 | 戻る額（1 ラインの賭け金の何倍） |
| --- | --- |
| 7 7 7 | 300 |
| BAR 3 つ | 50 |
| ベル 3 つ | 20 |
| スイカ 3 つ | 15 |
| レモン 3 つ | 10 |
| チェリー 3 つ | 20 |
| チェリー 左から 2 つ | 4 |
| チェリー 左に 1 つ | 1 |

既定の配当で還元率 96.0%、5 ラインのどれかで何か戻る確率 65.4% です（チェリー 1 つなどは賭け金より少ない戻り）。`slot.bets` は 5 の倍数だけ使えます（`config.yml` の `slot.paytable` で変えられ、起動時のログに還元率が出ます）。リールの絵柄の並びは `common` の `Reels` と `tools/gen_slot.py` で同じにしてあります。

### 賭け場所を選ぶ卓（バカラ・ビッグホイール・チンチロ・ハイ＆ロー・競馬。競馬は 6 席、ほかは 5 席）

座ると賭けのメニューが開きます。上の段に賭け場所、下の段に 1 回に置くチップの額（10〜1000）・賭けた合計・全部取り消し・ルールブック・席を立つが並びます。何か所にも置けて、同じ場所をもう一度クリックすると積み増します。最初の人が賭けてから締め切り（既定 15 秒、ハイ＆ローは 12 秒）で勝負が始まり、負けたチップはディーラーの前へ集まり、勝った分は小さなチップで賭け場所へ払い出されます。いつでもスニークで立って歩けます（`standing-range`）。設定は `config.yml` のゲームごとの節（`min-bet` `max-bet` `max-total` `betting-seconds` `buy-ins` `standing-range`）です。

- **バカラ**（プント・バンコ、8 デッキ）: 席ごとの枠にプレイヤー・バンカー・タイ・ペアを賭けます。最初の 4 枚は伏せて配り、プレイヤー側・バンカー側の順にめくります。3 枚目の規則はディーラーが自動で処理します。配当はプレイヤー 2 倍、バンカー 2 倍から 5% の手数料、タイ 9 倍（プレイヤー・バンカーへの賭けは戻る）、ペア 12 倍。
- **ビッグホイール**（54 マス、ステージ型）: 赤い幕のステージに直径 3 ブロックのホイールを立て、まわりの電球が点滅します（回っている間は速く）。客はホイールを囲む扇形のバースツールに座り、チップは各席の前のベット台に積まれます。置くには幕の列（4 x 1 ブロック）に高さ 5 ブロックの空きと、手前に椅子を並べる場所が要ります。上の針が指したマスの絵柄に賭けていたら当たり。1（24 マス）2 倍、2（15）3 倍、5（7）6 倍、10（4）11 倍、20（2）21 倍、ジョーカー・ロゴ（各 1）41 倍。針の上に、今指しているマスの絵柄が出ます。
- **チンチロ**（サイコロ 3 個、座敷）: 4 x 4 ブロックの畳の真ん中にどんぶりを置き、まわりの座布団に客 5 人と親（ディーラー）が床に座ります。客は子として額だけを張り、まず親が振り、そのあと子が 1 人ずつ順に振ります（自分の番はチャットの [振る] か `/casino roll`、どんぶりのクリック。放っておくと自動で振ります）。1 回の番で 3 回まで振れ、役が出たらそこで止まります。役は強い順にピンゾロ（5 倍）・ゾロ目（3 倍）・シゴロ（2 倍）・目（2 つそろったときの残り 1 つ、1〜6）・目なし・ヒフミ（2 倍払い）。親がピンゾロ・ゾロ目・シゴロ・6 の目なら子は全員その倍率で負け、1 の目・目なし・ヒフミなら子は全員勝ち。親が 2〜5 の目のときだけ子が振って親と比べ、勝った側の役の倍率で払い、同じなら引き分けです。負けると賭け額より多く払うことがあるので、賭けたあとも手元に賭け額の 4 倍のチップが必要です。置くには 4 x 4 ブロックの平らな場所が要ります。
- **ハイ＆ロー**: 表向きの基準のカードより、次のカードが上か下か同じかに賭けます（A が 1、K が 13）。配当は当たる確率から決まり（還元率 95% 以下）、枠の上に倍率が出ます。めくったカードが次の基準になり、奥に履歴が並びます。基準が A ならロー、K ならハイは出ません。
- **競馬**（6 頭、単勝、6 席）: 長さ約 10 ブロックの直線ダートコースを、左のスタートゲート（扉が開きます）から右のゴール板まで走ります。客は手前の 2 段の観客席に座り、チップは席の前のベット台に積まれます。置くにはコース（10 x 2 ブロック）に高さ 3 ブロックの空きと、手前に観客席（10 x 3 ブロック）の場所が要ります。レースごとに馬の強さが変わり、配当（勝つ確率の逆数の 90%）がコースの奥のオッズ板に出ます。馬の色は 1 白・2 黒・3 赤・4 青・5 黄・6 緑。着順を先に決め、その順にゴールするよう抜きつ抜かれつで走らせます。

権限は `luckycasino.place`（テーブルを置く、既定で全員）と `luckycasino.admin`（既定で OP）です。

## チップとお金

- `economy.mode` が `auto` なら、Vault の経済プラグインがあればそのお金、無ければ練習用チップ。`money-per-chip` でチップ 1 枚の値段を決めます。
- 席に着いている間のチップ（賭けている分を含む）を `plugins/LuckyCasino/chips.yml` に控えています。勝負の途中でサーバーが落ちても、次の起動時にお金に戻します。精算するときは控えを先に消してからお金を戻すので、二重には戻りません。
- チャンクの読み込みが外れたりサーバーを止めたりしてテーブルが片付くときは、勝負の途中でも賭け金をそのまま返して精算します。

## 自己テスト

`/casino selftest <種類> [回数]` は、ワールドの初期地点の近くに保存しない卓を出し、全席にボットを座らせて指定回数（既定 10）だけ勝負させます。毎回、次を確かめてサーバーのログに結果を出します。

- チップの合計が、配った分と払い戻し・賭け金の差し引きに一致する（ポーカーは席の間で動くだけ）
- 勝負の区切りで賭けたままのチップが残っていない
- 勝負の区切りで、カード・チップ・文字のエンティティが片付いている（ハイ＆ローの基準と履歴のカードのように、回をまたいで残す表示は除く）
- 進行中に例外が出ていない、進行が止まっていない

## リソースパック

`config.yml` の `resource-pack.url` と `resource-pack.sha1` を設定すると、参加した Java 版プレイヤーにパックを送ります。試験用に、ビルド済みの zip を `dist/` に置いています（GitHub の raw URL をコミット固定で指定して配信）。パックを変えたら `tools/` で `python3 gen_table.py`（カードは `gen_cards.py`、スロットは `gen_slot.py`、バカラ以降の卓は `gen_games.py`、実績のアイコンは `gen_icons.py`）を実行し、`./gradlew build` のあと zip を `dist/` へコピーして SHA-1 を更新してください。

```
Paper（hub / survival）                         Velocity
 ├ ItemDisplay … Java 版に見えるカード            └ Geyser-Velocity
 └ TextDisplay（文字も背景も空）… 運び役              └ LuckyCasino 拡張
      Java 版では何も描かれない                          運び役を luckycasino:card に差し替え
        │                                                  ↑
        └── LAN 内 TCP（共有鍵で認証）: 「この運び役は♠A・表向き」 ──┘
```

1. Geyser 拡張を入れて Velocity を起動すると `plugins/Geyser-Velocity/extensions/luckycasino/config.properties` ができ、共有鍵 `key` が自動生成されます。
2. Paper 側の `config.yml` の `bridge` に、Velocity マシンの LAN 内 IP、ポート（既定 `25590`）、同じ `key` を書いて再起動します。
3. ポートは LAN 内からだけ届くようにしてください。

裏向きのカードは番号 0 で送るので、通信や統合版クライアントから伏せ札は読めません。Geyser は API 2.11.0 以上が必要です。

## アニメーションのプレビュー

`dist/preview.html` をブラウザで開くと、各ゲームの 1 回分の勝負を、リソースパックのモデルとプラグインと同じ位置・tick で再生します（three.js を CDN から読み込みます）。モデルやテクスチャ、`tools/preview/preview.js`・`games.js`（賭け場所を選ぶ卓）を変えたら `tools/preview` で `python3 build.py` を実行して作り直してください。動きのタイミングを Java 側で変えたときは、`preview.js` / `games.js` の同じ箇所も合わせて直します。
